# degas-ui documentation

degas-ui is a React 19 application built with Vite. It talks to
[degas-api](../../degas-api/docs/index.md) over HTTP for metadata, loss
validation and sessions, and over a WebSocket for optimization runs.

| Page | Contents |
|---|---|
| [Using the interface](usage.md) | editors, loss arguments and CSV upload, run settings, examples, results, export, history |

To run the interface together with the API, use the
[local stack](../../../docs/local-stack.md). To work on the code, see
[Contributing](../../../CONTRIBUTING.md#degas-ui).
